# FixMyArea

## Overview

**FixMyArea** is a full-stack web application that allows residents to report community problems 
such as damaged roads, water supply issues, garbage collection, broken streetlights, and other public infrastructure problems. 
The system helps citizens report issues while providing a foundation for tracking and managing them.



## Features

* User Registration
* User Login & Authentication (JWT)
* Secure Password Hashing (bcrypt)
* Submit Community Reports
* View Report Details
* Reports Stored in PostgreSQL
* Dynamic Navigation Based on Login Status
* REST API with Express.js
